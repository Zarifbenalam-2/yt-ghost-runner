# StreamStress Ghost Runner (Cloud & Local)

High-performance, signed-out **Ghost Watcher** with real-time **Live Screen Feed Dashboard** and 100% **GitHub Cloud Runner** compute.

## Quick Start (Local Dashboard)

1. Launch Dashboard:
   ```bash
   python server.py
   ```
2. Open in browser: `http://127.0.0.1:8766`
3. Enter video link and click **"Run Local Test"** or **"Spawn Cloud Actions"**.
